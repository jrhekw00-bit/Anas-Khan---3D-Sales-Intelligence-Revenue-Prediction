# Sample Sales Datasets

This folder contains realistic sales demo datasets for **Anas Khan 3D Sales Intelligence**:

- `sales_data_demo.csv`: 90-day multi-product B2B software & cloud sales dataset containing:
  - `Date`: ISO 8601 date string (YYYY-MM-DD)
  - `Product`: Software/Cloud product name
  - `Category`: High-level business category
  - `Price`: Unit list price (USD)
  - `Quantity`: Units/licenses sold
  - `Discount`: Discount decimal applied (0.00 to 0.20)
  - `Ad_Spend`: Allocated campaign/advertising spend (USD)
  - `Revenue`: Final net revenue generated (USD)

You can also upload your own company CSVs via the **Data Management** panel with flexible column mapping.
